# نُوطة — مساحة الوسائط

معرض وسائط محلي باللغة العربية، في صفحة واحدة، ومتجاوب مع الهاتف والكمبيوتر. الواجهة تستخدم HTML وCSS وJavaScript وواجهات المتصفح الأصلية فقط؛ لا تعتمد على أي مكتبات أو أطر عمل أو خطوط أو صور أو خدمات خارجية.

## المزايا

- **الموسيقى:** اختيار ملفات متعددة، مشغّل صوت HTML5، السابق/التالي، التشغيل العشوائي، وترتيب قائمة التشغيل أبجديًا أو حسب وقت الإضافة.
- **الفيديو:** تشغيل ملفات الفيديو المحلية باستخدام عنصر HTML5، مع قائمة لاختيار المقطع.
- **الصور:** معرض متجاوب، عارض صور مع تنقّل سابق/التالي، وملء الشاشة عندما يدعمه المتصفح.
- تصميم عربي RTL يعمل على الهاتف والكمبيوتر، مع حالات تركيز مرئية ودعم تقليل الحركة.
- أدوات لمسح قائمة كل نوع من الوسائط وتحرير روابط الملفات المؤقتة.

## التشغيل

افتح `index.html` في متصفح حديث، ثم أضف الملفات من جهازك. يمكن إضافة المزيد لاحقًا أو مسح كل قسم على حدة.

## الخصوصية والاعتماديات

المشروع مستقل تمامًا: لا مكتبات JavaScript أو CSS، ولا CDN، ولا خطوط أو صور مستضافة، ولا تحليلات أو اتصالات شبكة. تُقرأ الملفات المختارة محليًا داخل المتصفح باستخدام واجهة الملفات وروابط `URL.createObjectURL`، ولا تُرفع إلى أي خادم. تُحرر الروابط المؤقتة عند مسح الوسائط أو مغادرة الصفحة. دعم صيغ الوسائط يعتمد على المتصفح ونظام التشغيل.
