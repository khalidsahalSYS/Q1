# مساحة الوسائط

معرض وسائط محلي باللغة العربية، في صفحة واحدة، ومتجاوب مع الهاتف والكمبيوتر. يستخدم HTML وCSS وJavaScript وواجهات المتصفح القياسية فقط؛ لا يعتمد على مكتبات أو أطر عمل أو خطوط أو صور أو خدمات خارجية.

## المزايا

- **الموسيقى:** اختيار عدة ملفات محلية، مشغّل HTML5، السابق/التالي، تشغيل عشوائي، وترتيب أبجدي أو حسب الإضافة.
- **الفيديو:** تشغيل الملفات المحلية في مشغّل HTML5 واختيار الفيديو من قائمة.
- **الصور:** معرض متجاوب، عارض صورة مع التنقل بين الصور، ودعم ملء الشاشة عندما يسمح المتصفح.
- تصميم RTL عربي متجاوب، مع دعم لوحة المفاتيح وتقليل الحركة.
- لا توجد اتصالات شبكة أو تحليلات أو رفع للملفات. الملفات المؤقتة تُنشأ محليًا عبر `URL.createObjectURL` وتُحرر عند مسح المحتوى أو إغلاق الصفحة.

## التشغيل

افتح `index.html` في متصفح حديث، ثم أضف ملفاتك من جهازك. يمكن إضافة المزيد من ال��سائط لاحقًا أو مسح كل قسم على حدة.

## الخصوصية والاعتماديات

المشروع مستقل تمامًا ولا يستخدم مكتبات JavaScript أو CSS خارجية، أو CDN، أو خطوطًا/صورًا مستضافة، أو أدوات تتبع. اختيار الملفات وتشغيلها يتمان محليًا داخل المتصفح. دعم صيغ الوسائط يعتمد على المتصفح والجهاز.
