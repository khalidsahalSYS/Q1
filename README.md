# مساحة الوسائط

معرض وسائط محلي في صفحة واحدة، باللغة العربية، ومتجاوب مع شاشات الهاتف والكمبيوتر. يعتمد على HTML وCSS وJavaScript المدمجة وواجهات المتصفح القياسية، دون مكتبات خارجية أو أدوات بناء.

## المزايا

- **قسم الموسيقى في الأعلى:** اختيار عدة ملفات صوتية، قائمة تشغيل، تحكم أصلي بالصوت، والانتقال للمقطع التالي عند انتهاء المقطع الحالي.
- **قسم الفيديو في الوسط:** مشغّل فيديو HTML5، مع قائمة لاختيار الملفات المحلية.
- **قسم الصور في الأسفل:** شبكة صور متجاوبة، مع عرض الصورة بحجم أكبر في نافذة منبثقة.
- تصميم RTL عربي يتكيّف مع الهاتف والكمبيوتر.
- تُقرأ الوسائط محليًا في المتصفح باستخدام روابط ملفات مؤقتة؛ لا تُرفع إلى خادم.

## التشغيل

افتح `index.html` مباشرةً في متصفح حديث، ثم اختر ملفات الصوت والفيديو والصور من جهازك. يمكن إضافة المزيد من الملفات لاحقًا بالضغط على أزرار الإضافة مرة أخرى.

> دعم صيغ الوسائط يعتمد على المتصفح ونظام التشغيل. لا يحتوي المشروع على خادم أو مكتبات خارجية.
